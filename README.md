# LynShred 1.0.0

**LynShred** 是一款简单、安全的文件彻底删除工具。  
通过多次覆写文件数据后再删除文件，使文件无法被常规手段恢复，适用于处理敏感文件。

---

## 功能特性

- **多种覆写标准**  
  支持三种国际认可的数据清除算法：
  - US Navy (3 遍覆写)  
  - DoD 5220.22-M (7 遍覆写)  
  - Gutmann (35 遍覆写)

- **友好的图形界面**  
  基于 PySide6 开发，支持文件/文件夹添加、拖放操作，进度实时显示。

- **固态硬盘（SSD）提示**  
  在 Windows 下会自动检测文件是否位于 SSD 上，并提醒用户覆写删除在 SSD 上可能无法彻底清除数据（因磨损均衡等机制）。

- **灵活的添加方式**  
  - 手动选择单个或多个文件  
  - 选择文件夹（递归包含所有子文件）  
  - 直接将文件/文件夹拖拽到程序窗口

- **可随时取消**  
  粉碎过程中支持取消操作，程序会安全终止正在处理的文件。

- **零依赖？只需 PySide6**  
  纯 Python 编写，除 PySide6 外无需其他第三方库。

---

## 运行要求

- Python 3.7 及以上版本（推荐 3.9+）
- PySide6 库
- Windows 操作系统（SSD 检测功能依赖 `fsutil` 命令，非 Windows 下仍可正常粉碎文件，只是不进行 SSD 提示）

---

## 安装与使用

### 1. 安装依赖
```bash
pip install pyside6
```

### 2. 下载源码
```bash
git clone https://github.com/lynvortex/lynshred.git
cd lynshred
```

### 3. 运行程序
```bash
python lynshred.py
```

如果需要程序显示图标，请将图标文件 `icon.ico` 放在与脚本相同的目录中。

---

## 使用说明

1. **添加文件**  
   点击「添加文件」选择要粉碎的文件，或点击「添加文件夹」添加整个目录下的所有文件。  
   也可以直接拖拽文件/文件夹到程序窗口。

2. **选择擦除算法**  
   在下拉框中选择需要的覆写标准：
   - 普通文件推荐使用 **DoD 5220.22-M (7 遍)**  
   - 极度敏感文件可选择 **Gutmann (35 遍)**，但速度较慢  
   - 一般清除可使用 **US Navy (3 遍)**，速度较快

3. **开始处理**  
   点击「开始处理」按钮，确认操作后将启动粉碎任务。  
   - 如果是 SSD 上的文件，程序会弹出风险提示，确认后继续。  
   - 处理过程中可随时点击「取消」按钮中止任务。

4. **完成**  
   粉碎完成后，程序会报告处理结果，列表自动清空。

---

## 重要提醒

- **不可逆性**  
  文件经过覆写删除后无法恢复，操作前请务必确认文件内容不再需要。

- **SSD 的数据残留风险**  
  由于固态硬盘的磨损均衡、垃圾回收以及日志型文件系统（如 NTFS 的 USN 日志）等原因，即使经过多次覆写，原始数据仍可能残留在磁盘物理层或备份区域中。  
  对于高度敏感的数据，建议采用**全盘加密**或**物理销毁**的方式确保数据安全。

- **权限问题**  
  部分系统文件或只读文件可能因权限不足而无法覆写，届时程序会报错并停止。
